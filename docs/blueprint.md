# **App Name**: Mindful AI

## Core Features:

- Chatbot Support: AI-powered empathetic chatbot that offers emotional support and coping strategies.
- Anonymous Check-ins: Anonymous mental health check-in via conversational interface.
- Mood Journal: Mood tracking with a journaling feature to record daily emotions.
- Emergency Support Tool: Suggest emergency contacts using an AI tool when detecting severe distress. LLM must use reasoning to determine if user inputs require redirection to support resources.
- Calming Exercises: Integrated calming techniques such as guided meditations and breathing exercises.
- Dark Mode Option: Offers a toggle for dark mode to facilitate a relaxing visual experience, particularly during high-stress periods or nighttime use.

## Style Guidelines:

- Primary color: Soft lavender (#E6E6FA) to promote calmness.
- Background color: Light gray (#F0F0F0) for a neutral, soothing backdrop.
- Accent color: Pale teal (#A0D6B4) for highlights and interactive elements, fostering tranquility.
- Body and headline font: 'PT Sans', a humanist sans-serif offering both a modern look and a touch of warmth, ensuring readability and approachability.
- Use simple, minimalist icons that represent emotional states and calming activities.
- Clean, intuitive layout with plenty of white space to avoid overwhelming the user.
- Gentle, unobtrusive animations for feedback and transitions, avoiding any jarring effects.
